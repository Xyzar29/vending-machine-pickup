An entry for the [make.fun](https://make.fun) bounty **"One Line, One Minute: The Vending Machine Pickup Line Contest"** — write one pickup line, 200 characters at most, that a vending machine would use on a passing human.

## The line

> I hum for a thousand strangers a day, but you're the only snack my coil ever gets stuck on.

91 characters. Spoken by the machine itself, from its own world — the hum, the passing strangers, the snack, the coil — with the punch landing in the last few words: a stuck coil, the machine's classic failure, reframed as being unable to let go of one particular human.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (exactly the line, no trailing newline).
